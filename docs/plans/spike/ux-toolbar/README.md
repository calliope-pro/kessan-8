`npm ci` のあと、リポジトリ直下の `@playwright/test` で動く。`index.html`・`toolbar.css`・`toolbar.js` が試作のバー (`?calc=single|wrap&text=差 …|比 …`)。

## 測った結果 (2026-11-04、macOS、Playwright 1.64.1 の Chromium・WebKit・Firefox。実機ではない)

- **バーの高さは 61 px (padding 8 + 的 44 + padding 8 + 上の線 1)。幅 320・360・375・414 px、3 つのエンジン、検算の結果が「なし」から 18 文字までのどれでも変わらない (折り返してバーが高くなることは無い)。横スクロールは起きない。印スイッチは 44 × 44 px、「判定する」は 85〜103 px × 44 px**
- 検算の結果に使える幅は、320 px で 154 px (Chromium・Firefox。WebKit は 159 px)。文字を 120% にすると 141 px
- 検算の結果を **1 行に固定**すると (`single`)、100% の文字で、320 px では「差 −1,234,567 / 比 0.83」(7 桁) から欠ける。360・375 px は「差 +1,234,567,890 / 比 123.456」(10 桁) だけ欠け、414 px は欠けない。文字 120% では、320 px で「差 +1,234 / 比 1.05」でも欠ける
- 検算の結果を **2 段まで許す** (`wrap`。「差 …」「比 …」を縦に並べる。バーは 61 px のまま) と、100% の文字では、全幅・全エンジンで 10 桁まで欠けない。120% でも、欠けるのは 320 px の 10 桁だけ
- 試作の資料 (hand-q01) の数字は最大 5 桁 (15,200 百万円)
- `sessionStorage`: 再読み込みで残る。`window.open` で開いたタブには、開いた時点の値が複製される (以後は別々)。新しいタブには無い (3 エンジンとも同じ)
