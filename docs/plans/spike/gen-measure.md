### 整合 (hard) の規則 (63)

貸借の内訳の和と合計 (前期末・当期末 各 9: 流動資産・固定資産・資産合計・流動負債・負債合計・株主資本・純資産・負債純資産・**貸借の等式**)、損益の連鎖 (前期・当期 各 6: 総利益 → 営業利益 → 経常利益 → 税引前 → 純利益 → 親会社帰属)、CF の内訳と合計 (6)、**CF の連動**(起点 = 損益の税金等調整前当期純利益 (日本基準。research.md §2.3)・期末残高 = 貸借の現金・期首 = 前期末の現金・売上債権/棚卸資産/仕入債務/その他の増減 = 貸借の差額・法人税等の支払 = 損益の法人税等 − 未払法人税等の増減・利息・固定資産の期首 + 取得 − 償却 = 期末・借入の増減・利益剰余金 = 前期 + 親会社帰属 − 配当・非支配持分・資本金不変、計 15)、サマリーと財務諸表の一致 (1)、比率の再計算 (増減率 4・EPS・自己資本比率・ROE・BPS・配当性向・配当金総額 = 配当 × 株数、計 10)。規則の出所は、複式簿記の定義と research.md §2.3 (導いた)。

### もっともらしさ (soft) の規則 (11)

BS 全項目 ≥ 0・流動比率 0.8〜4・自己資本比率 20〜80%・営業利益率 −5〜25%・売上増減 ±20%・営業利益あり・実効税率 25〜40%・営業 CF / 営業利益 0.3〜3・現金が売上の 3〜40%・配当性向 ≤ 100%・増減率が全部表示できる。**範囲の値は、本試作での仮定** (出典なし。会計の分かる人の確認は未実施)。

## 測った通過率

| 方式 | N | 整合 (hard 63) を全部通った | もっともらしさ (soft 11) を全部通った | 両方 |
| --- | --- | --- | --- | --- |
| **S2 構築** (前提の範囲は妥当) | 1,000 / 20,000 | **100.0% (1,000/1,000・20,000/20,000)** | 94.4% / 93.8% | 94.4% / 93.8% |
| S2 構築 (前提を広げる: 売上 −40%〜+60%) | 1,000 / 20,000 | 100.0% | 38.1% / 36.6% (落ちる主因は「売上増減 ±20%」の規則。意図した対照) | 38.1% / 36.6% |
| S1 素朴 (独立の乱数) | 1,000 | **0.0%** (どの 1 件も、前期末の貸借の合計から落ちる) | 19.6% | 0.0% |

読みかた (導いた):
- **整合は、導出の順序で作れば 100%**。数字を決めてから合計を足し上げ、貸借の差額を現金と利益剰余金から出す、という順にすれば、会計の等式・損益の連鎖・CF の連動は、乱数の種によらず外れない (20,000 件で 0 件)。S1 の 0% は、検証器が空振りしていない証拠でもある。
- **ただし 100% は構築の性質で、生成の難しさを測った値ではない**。生成器と検証器を同じ者が書いた。検証の規則の抜けは、この測定では見つからない。規則の網羅は、会計の分かる人の確認 (plan-comparison の C-G10) でしか確かめられない (未確認)。
- soft の 5〜6% の落ちは、前提の範囲が広くて「正常に見えない」数字が出る分 (流動比率・自己資本比率・営業利益率など)。範囲を絞る調整か、落ちたら捨てて再生成 (棄却) で 100% にできるが、棄却の割合は上の 6.2%〜6.6% で、生成は 0.2 ms なので費用は無視できる (導いた)。soft の範囲の妥当性は人間・会計の分かる人の好みで、測れない。

## 変異の検証 (検証器が空振りしていないか)

正常データ 50 件 × 全項目 (BS・PL・CF・サマリー) の 1 つの数字を +1 (百万円。比率は最後の桁) した 5,950 件:
- **検出 5,950/5,950 = 100.0%** (検出されなかった項目なし)。
- 1 つの数字を変えて落ちた規則の本数: 中央値 2・平均 1.8・最大 6・**1 本だけ 1,720/5,950 (29%)**。区分別: サマリーの比率 100%、損益 45%、貸借 8%、CF 4%。→ 貸借・CF の 1 項目だけを変えると、2〜6 本の規則が同時に落ちる。**「異変が 1 つだけを変える」(plan-comparison C-G9) には、変えた数字の下流を表示上つじつまが合うように再計算する作業が要る**。

## 異変の注入 (inject.py。副産物。6 種類)

1 か所を書き換え、意図した食い違い以外の下流は再計算して、検証器が想定した規則だけを落とすかを確かめた (各 200 件):

| 異変 | 想定どおりの規則だけが落ちた |
| --- | --- |
| 計算: 増減率のずれ | 200/200 |
| 見た目: サマリーの桁違い | 200/200 |
| 計算: 合計が内訳の和と合わない | 200/200 (落ちるのは 2 規則) |
| 会計: 貸借が合わない (買掛金) | 200/200 (2 規則) |
| 会計: CF の起点が当期純利益 | 200/200 (2 規則) |
| 会計: 利益剰余金の連動 | 200/200 (2 規則) |

**途中の失敗 (記録)**: 最初の版は、貸借を書き換えても、サマリーの総資産・純資産・自己資本比率・BPS・ROE を再計算しなかったため、貸借を書き換える 3 種類は 0/200 だった (想定外の規則が 3〜6 本落ちた)。サマリーを再計算する関数 (`_resum_summary`) を足して 6/6 になった。**貸借を触る異変は、サマリーへの漏れを塞ぐ作業が要る**(1 種類につき数行〜、共通の関数で済んだ)。
