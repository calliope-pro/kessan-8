## 3. 期と段

### 3.1 期 (決算期の年)

- **すべて 2019〜2022 年の決算期**。発表日が公開 (2026-11) より前になる。未来の発表日は、E-04 (期・日付の食い違い) を覚えた遊び手に、正常な問題が異変に見えるため (やさしい §3 と同じ理由)。やさしいは 2023〜2025 年なので、**会社 × 期は両難易度で重ならない**。
- **会社ごとに連続した期で、前期の当期 = 次期の前期** (1 本の時系列)。同じ会社を何度か見た遊び手の記憶と数字が食い違わない。各社の最後の期は 2022 年。問題 ID は ID の若い順に古い期へ割り当てた (表の「期」の列)。
- **やさしいの時系列とのつなぎ**: やさしいの各社の最初の期 (2023 年) の前期の数字を、むずかしいの 2022 年の当期の数字に揃えると、1 本の時系列になる。揃えるかは #25 の組との相談で、責任者を通す (§7)。揃えなくても、期が重ならず未来の日付も無いので、遊びは成り立つ。

### 3.2 段 (`tier`) の決めかた

experience.md §6.7 の `Problem.tier` の定義に従う。**11 : 9 : 5 (±1)** は、k 社目に着く回数の比 43 : 38 : 19 に合わせたもの (experience.md §4 案 U3、導いた)。

- **異変あり**: 異変の目立ち方。段 1 = 見た目や大きな差で気づく (監査済みの記述・桁違い・貸借の大きな不一致・セグメントの欠け・逆の語)。段 2 = 資料を見比べると分かる (CF の起点・IR と短信の食い違い・注記の食い違い)。段 3 = 差が小さく紛らわしい (利益剰余金・有形固定資産・仕入債務の増減が、足し引きしないと分からない)。
- **異変なし**: 正しいが疑わしく見える要素の数。0 個 = 段 1、1〜2 個 = 段 2、3 個以上 = 段 3 (仮定)。**書式・表記・単位・科目名の違いは正常な問題に使わない** (E-03・E-05・H-17・H-28 の異変の種類で、検証器が正常な問題の `signOverrides`・`unitOverrides`・`labelOverrides` を落とす。#26 の追加)。

## 5. 使う種類と使わない種類

使う 16 種類: 会計 = H-01・H-02・H-03・H-05・H-06・H-09・H-28、資料間 = H-13・H-15・H-16・H-17・H-19・H-21、注記 = H-22・H-23・H-24。

使わない 9 種類 (確度 A・B のうち): H-04・H-07・H-08・H-10・H-11・H-12・H-14・H-18・H-20。理由: 32 問に 16 種類を 1 問ずつ入れる範囲に絞った (期限のため)。H-11 は ROE の条件 (ROE² × (1 − 配当性向) ÷ 2 ≧ 0.3 ポイント) を満たす資料束が要り、H-12 は非支配株主持分のある資料束が要るので、後から問題を足すとき (公開後の訂正の範囲外。方針の見直しの条件「公開後に問題を足すとき」) に使う。**使わない種類を、後から足す場合は、問題のデータを足すだけでよい** (design.md の原則「保守性」)。確度 C の H-25〜H-27 は使わない (責任者の決定)。

## 6. 正常な資料の数字のつくりかた (#74 への指定)

- 会社ごとの規模・営業利益率・自己資本比率の目安は companies.md §5.1。検証器の規則 (hard) は全部満たし、参考の規則 (soft) も満たすように作る (c07 の自己資本比率は目安の 18% でなく soft の範囲 20% 以上に収める)。
- 連動 (CF と貸借・損益、利益剰余金、固定資産の増減、借入金、配当) は anomalies.md G5 の単純化に従う。**換算差額は全社 0**。配当は T4 の支払額 = 前期の期末配当 + 当期の中間配当 (T1 の配当金総額とは別)。
- 億円の会社 (c03・c05・c06・c08・c10) の IR は、短信の百万円 ÷ 100 を小数第一位に四捨五入した値。IR の中の式 (セグメント利益の合計 + 調整額 = 連結、純有利子負債) が丸めても一致するよう、セグメント利益・調整額・有利子負債・現金を 10 百万円の倍数にする (design.md §4.1)。
- 文章 (`ir.statements`) は、主張 (`claims`) が短信の数字の動きと合うものだけ。程度の語 (「堅調」など) は主張にしない。
- 会社の口調 (companies.md §5.3) を、IR の文章に使う。
