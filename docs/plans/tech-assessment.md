## 1. 結論

1. **手書き 1 問の制作は、計画の 0.5 h より桁違いに小さい。** 短信 5 画面分のデータ + 異変 1 つ + 答え合わせの文面を作るのに、外で確かめられる上限で **2 分 34 秒** (測った、n = 1、AI が作成)。0.5 h の **1/11 未満**。ただし、画面の描画・企業名の衝突の確認・一次資料での確認・レビューの往復は含まない (別の項目で、置き換えていない)。案 B の資料束 1.0 h (IR 側) は **測っていない**。
2. **生成した正常データが会計の整合を満たすことは、測れる範囲で満たした。** 1 期分の連結 3 表 + サマリーを導出の順序で作ると、整合 (68 規則: 貸借の等式・損益の連鎖・CF の連動・比率・表示値どうしの別経路の突き合わせ) を **1 回目で 99.66%、引き直しで 100%** (N = 20,000、最大 3 回)。素朴な独立乱数は 0%。→ plan-comparison §3.3 のリスク「整合を満たせるかが未測定」は、**コアの範囲では「満たせる」に変わった**。範囲外 (注記・IR 側・資料間の矛盾・25 種類) は未測定。規則の網羅は会計の分かる人の確認が要り、未確認。
3. **案 B と案 C の総工数の順位は、plan-comparison §5 の逆転の条件 (手書きが 2 倍遅い) では逆転しない。** 手書きは計画より遅いどころか 1/11 以下。ただし**別の経路で逆転しうる**: 手書きを測った値に置き換えたうえで、生成まわり (G5〜G9) の工数が計画の約 12% 未満に収まれば、案 C が案 B を下回る。試作の経過から導いた生成の倍率は 0.012〜0.015 で、この範囲に入る。→ **総工数の大小では B と C は同点 (差 ±10 h 前後、総工数 約 110〜120 h の 1 割未満)**。推奨 (案 B) の導出は工数の大小に依らない (§6 の 1・2・5) ので、**推奨は変わらない**。ただし導出の 3 (取り消しの費用)・4 (実現性が未測定) は弱まる (§3.3)。
4. **新しく分かった技術のリスク 3 つ** (§5): 表示値どうしの別経路の突き合わせで「正常が異変に見える」例が出る (配当性向で 0.34%。初版の 100% は規則の抜けで高く出ていた)・貸借や CF の 1 項目を変える異変は 2 本以上の規則を同時に壊す (単独の異変にするには下流の再計算が要る)・「正常だが異変に見える」書き方 (特別損失など) は一次資料での確認でしか拾えない。
5. **見積もりの単位**: 測った時間は AI (進める役) の経過時間で、計画の h は「組の作業時間」。レビューの往復は、制作に対して 0.7〜1.9 倍かかった (n = 2)。計画の係数 1.5 (往復 = 実装の 5 割) より重い。単位をそろえる判断は責任者 (§6)。

## 3. 案 B と案 C の逆転の判定

### 3.1 plan-comparison §5・§6 の条件

§6: 「手書きの制作が想定の 2 倍以上遅く、かつ生成した正常データが会計の整合を満たすと測れたとき、案 C の総工数のほうが小さくなりうる」。

- **前半 (手書きが 2 倍以上遅い): 満たさない**。短信 1 問の上限 2 分 34 秒 ÷ 計画 0.5 h = 0.086 倍 (測った / 導いた)。2 倍を否定するには 1 問全体の上限が要るというレビューの指摘に従い、サマリーだけでなく 5 画面分で測った。IR 側は未測定 (仮定)。
- **後半 (生成が整合を満たす): 満たす** (コアの範囲。§2 #2)。
- **判定: 条件の前半を満たさないので、§6 が定義した逆転は起きない**。

### 3.2 別の経路: 手書きが速くなると、生成の倍率が効く

`spike/reversal.py` (estimate.py を読み込み、問題制作 B5〜B8 と生成まわり G5〜G9 だけを縮める。一次資料の確認 A8・B9・G10 は縮めない。**plan-comparison の estimate.py の scale_content は確認も縮めるため、ここでは別に出した**)。`cd docs/plans/spike && python3 reversal.py` で再現できる。

- 計画の仮定のまま: 案 A 102.2・案 B 159.8・案 C 178.2 h (総工数)。
- 手書きだけを測った値 (s = 0.09) に置き換えると: 案 A **81.8**・案 B **118.8**・案 C 178.2 (C − B = +59.5 h)。
- **案 B の総工数が案 C を超えるのは、生成が計画のとき手書きの単価が計画の 1.41 倍を超えるとき**(導いた: s > 1.41)。測った s = 0.09 は遠い。
- 生成の倍率 t を動かす (s = 0.09 固定、K = 1.5):

| t (G5〜G9 の計画に対する倍率) | 案 B (総工数 / パス) | 案 C (総工数 / パス) | C − B |
| --- | --- | --- | --- |
| 1.0 (計画のまま) | 118.8 / 60.1 | 178.2 / 98.0 | +59.5 |
| 0.3 | 118.8 / 60.1 | 131.0 / 66.5 | +12.2 |
| **0.119 (境目)** | 118.8 | 118.8 | 0 |
| 0.1 | 118.8 / 60.1 | 117.5 / 57.5 | −1.3 |
| 0.015 (試作から導いた) | 118.8 / 60.1 | 111.8 / 53.7 | −7.0 |

- t の導出 (**導いた。大きな不確かさ**): 試作が覆った範囲の計画時間を、G5 の約半分 (0.5 × 12 h) + G9 の約 8 割 (0.8 × 8 h) + 注入 6 種類 (6 × 1.0 h) = 約 18 h と数え (覆った割合は本ページでの判断で、**仮定**)、試作の経過 約 13 分 (0.22 h)〜外で確かめられる上限 16 分 55 秒 (0.28 h) で割ると 0.012〜0.015。**範囲外 (注記・IR 側・資料間の矛盾・19 種類の注入・テンプレートの設計 G4・一次資料での確認 G10) の単価は、範囲内より重い可能性が高い**ので、t は 0.015 より大きいと見るのが自然で、0.119 を下回るかどうかは決まらない。
- K を 2.0・2.9 にしても (§4)、t = 0.1 で C − B は −1.9・−3.0、t = 0.3 で +16.1・+23.1 h で、符号の境目はほぼ同じ (t ≈ 0.1) で動かない。

### 3.3 判定と推奨への影響

- **総工数の順位は、手書きを測った値に置き換えると「B < C が計画のまま」から「ほぼ同点」に変わる** (差は ±10 h 前後、総工数約 110〜120 h の 1 割未満)。どちらが小さいかは、**測っていない生成の範囲外の単価**で決まる。
- **推奨 (案 B) の導出** (plan-comparison §6) への影響:
  1. 「人間の言葉を満たす案に絞る」→ 変わらない (案 A を既定にしない理由)。
  2. 「案 C の違いは問題の作りかただけ。無限に出せるのは人間が言っていない価値判断」→ 変わらない。
  3. 「取り消しの費用が非対称 (失敗時に 79.5 h を捨て 63 h を足す)」→ **弱まる**。整合が満たせない可能性は、コアの範囲では下がった (測った)。ただし損失の大きさ (h) は単位が変わると縮み、範囲外 (注記・資料間の矛盾) は未測定。
  4. 「技術の実現性が未測定」→ **コアの範囲では解消**。残る実現性の未測定は、注記・IR・資料間の矛盾・規則の網羅 (会計の分かる人の確認)・「作り物らしさ」(好み)。
  5. 「規模の参照 (先行例 約 2.5 日・2 者で 41 問)」→ 変わらない。
- したがって**推奨は、工数の大小でも実現性でもなく、1・2・5 (人間の言葉に無いものを買わない) に依る**。責任者が推奨を維持するか、案 C の利点 (問題が尽きない) を人間に問うかは、責任者の判断。

## 5. 新しく分かった技術のリスク (測った)

1. **表示値どうしの別経路の突き合わせで、正常が異変に見える** (測った)。初版は規則 63 本で 100% だったが、レビューが「配当性向 = 配当金総額 ÷ 純利益で作った表示値が、遊び手が 1 株当たり配当金 ÷ EPS で検算した値と 0.1 pt ずれる」例を見つけた (N = 20,000 の配当がある 16,627 件のうち 62 件、0.37%)。別経路 5 規則を足して測り直すと 69/20,000 (0.34%) で落ち、**棄却して引き直す**と 100% になった。→ 「計算」の段の遊び手は表示値だけで検算するので、**生成の検証は表示値から別の式でも突き合わせる必要がある**。手書き (案 B) も同じ穴がある。配当性向の正の式の出所は未確認 (JPX 作成要領 PDF は 403 で取得できず、検索でも算式の出典が見つからなかった)。両方の式に合うものだけを通す方針で回避した。
2. **異変の注入は、1 つの数字を変えるだけでは単独の異変にならない** (測った)。正常データの 1 項目を +1 すると、検証が検出するのは 100% (6,000/6,000)、ただし落ちる規則が 1 本だけになるのは 25% (サマリーの比率 70%・損益 45%・貸借 8%・CF 4%)。貸借・CF を書き換える 3 種類の注入は、最初の版では想定外の規則が 3〜6 本落ちた (サマリーに漏れた)。サマリーを再計算する関数を足して 6 種類とも想定どおり (200/200)。→ 25 種類の異変は、**種類ごとに「どの規則だけを落とすか」を決め、下流を表示上つじつまが合うように再計算する作業が要る**。計画の「異変の注入 1 種類 1.0 h」は、貸借・CF の異変では妥当か、やや軽い (見立て。6 種類の実績: inject.py 約 100 行)。
3. **「正常だが異変に見える」書き方が、規則の外にある** (見立て)。例: 特別損失を現金払いとして整合させているが、減損・除却損と読む遊び手は CF に足し戻しが無いことを異変と判断する。生成の検証 (整合) では拾えず、一次資料での確認 (A-A8・B9・G10) でしか拾えない。→ **一次資料での確認の単価 (0.25〜0.4 h/問) は今回の測定で置き換わらない**。

## 6. 責任者へ渡すもの (決めるのは責任者)

- **単位の置きかた**: plan-comparison の h は「組の作業時間」。今回測れたのは AI の経過時間 (分単位)。**h の単位を人間の作業時間のまま保つか、AI の経過時間で置き直すかを決める**必要がある。置き直すなら、基盤・テンプレート・一次資料の確認・包括レビューなど、**測っていない項目も同じ尺度で見直す**必要がある (本ページで置き換えたのは #1 だけ)。この選択で総工数の絶対値は 10 倍以上変わりうるが、案のあいだの順位への効きは §3 のとおり小さい。
