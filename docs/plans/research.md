読み取り: 定型は無い。3 本 (CREX・マネーフォワード・felo) に実際に共通するのは「財務の要点 (業績サマリ・財務ハイライト・財務データ) を置く」ことと「補足・付録を置く」こと。セグメント別・見通し・補足/注記は CREX と felo の 2 本が共通。株主還元は CREX だけ。マネーフォワードの例 (表紙・目次・経営概要・財務データ・事業戦略・リスク要因・ESG 情報・付録) にはセグメントも株主還元も無い。 **導いた** (3 本の項目の突き合わせ)。IR 画面の数は、共通する「財務の要点」「補足」を必須、2 本共通の「セグメント別」「見通し」を準必須として設計の Sub-task で決める。ゲーム用の IR 画面は、架空の会社の資料として自由に作る (仮定)。実在の企業の資料は開いていない (要件で実在企業を使わない)。チャートの作法 (軸が 0 から始まらない、単位の欠落、前年の併記なし) は、見た目の異変の材料になる (導いた)。
定性の記述 (「増収増益」「見通し」) と数字の矛盾も、異変にできる (導いた。出所は本プロジェクトの定義)。

### 2.3 異変にできる整合性の決まり (会計の等式と、粉飾の典型)

| 異変の種類 | 内容 | 印 | 出典 |
| --- | --- | --- | --- |
| 見た目の異変 | 誤植・桁・単位 (百万円と千円)・符号・百分率の取り違え、同じ数字の 2 か所の食い違い (サマリーと財務諸表など) | 導いた (会計の知識が要らない種類。出所は本プロジェクトの定義) | |
| 計算の異変 | 合計が内訳の和と合わない。増減率が前期比の数字から計算した値と合わない。サマリーの比率 (自己資本比率・営業利益率など) が表の数字から計算した値と合わない | 導いた (四則演算で確かめられる。比率の項目は §2.1 のサマリー様式にある) | JPX (§2.1) |
| 貸借対照表の等式 | 資産の合計 = 負債の合計 + 純資産の合計。日本の財務諸表等規則は、資産・負債・純資産を資産の部・負債の部・純資産の部に分けて記載すると定め (第 12 条)、貸借対照表は様式第五号で記載する。等式そのものを書いた条文は見つからず、様式の合計欄が一致するという形で表れる | 文書にある (部の区分は原文)。等式は導いた (複式簿記の定義。条文に等式の文言は無い) | [財務諸表等規則 (e-Gov 法令)](https://laws.e-gov.go.jp/law/338M50000040059) 第 11 条・第 12 条。試したこと: 規則本文で「負債純資産合計」「資産の合計額から負債の合計額」を検索 (0 件)。様式第五号の表本体は XML の本文から読めていない (未確認) |
| キャッシュ・フローの起点 | **日本の基準では、営業活動によるキャッシュ・フローの間接法は、税金等調整前当期純利益から始める** (当期純利益ではない)。非資金項目・営業に係る資産と負債の増減・投資活動と財務活動の区分に含まれる損益項目を加減する | 文書にある (原文) | [企業会計審議会 連結キャッシュ・フロー計算書等の作成基準](https://www.fsa.go.jp/p_mof/singikai/kaikei/tosin/1a907a2.htm) 第三 一 2 |
| キャッシュ・フローの資金 | 資金の範囲は「現金及び現金同等物」。貸借対照表の「現金及び預金」とは範囲が違いうるので、**期末残高の貸借対照表科目別の内訳を注記する** (注記事項)。したがって「貸借対照表の現金及び預金 ≠ キャッシュ・フローの期末残高」は、それだけでは異変にならない | 文書にある (原文) | 同上 第二 一・第四 1 |
| 現金の連動 | 期首の現金及び現金同等物 + 現金及び現金同等物の増減額 = 期末の現金及び現金同等物。ただし**増減額は「営業 + 投資 + 財務」だけでなく、「現金及び現金同等物に係る換算差額」(区分表示) を含む**。したがって「営業 + 投資 + 財務 ≠ 増減額」は、換算差額などの行が見えている画面では正常。正常なデータを作るときは、これらの行を明示するか、ゼロとして示す | 文書にある (換算差額は原文)。期首 + 増減 = 期末は導いた (同じ計算書の内部の定義) | 同上 第三 三 |
