### 1.2 型の核を一文にすると (**導いた**: 上の表から)

> **同じ光景を何度も見せ、「いつもと同じか」だけを問う。答えは進むか戻るかの二択で、誤りは全てを失うが、やり直しは一瞬。**

核になっている要素と、そうでない要素を分ける。

| 核 (欠くと別のゲームになる) | 核ではない (置き換えられる) |
| --- | --- |
| 1. **正常を見せてから問う**: 異変の無い最初の通路で正常を見せ、そのあとも毎周ほぼ同じ見た目で繰り返す。遊び手が「いつもの姿」を覚えるまで見せる | 地下通路・ホラーの味付け・3D の歩行 |
| 2. **二択の判定**: 進む / 戻る (異変あり・なし) のたった一つの操作 | 見た目・音・登場人物 (おじさん) |
| 3. **数える目標**: 8 回連続という短い目標 (連続の途中経過が見える) | 「8」という数そのもの |
| 4. **失敗のコストは高いが、再開は一瞬**: 全部失う代わりに、待たずにまた始まる | 追われる異変 (6 種類) などの驚かせ方 |
| 5. **異変の幅と出し方**: 見落としそうな細部から、見れば分かるものまでが混ざり、見つけるほど残りは気づきにくいものに偏る。そのため全部を警戒させられる | 異変の中身そのもの |
| 6. **説明を世界の中に置く**: 規則は世界の中の短い掲示だけ。タイトル画面を置かない。詰まる所 (続編の電光掲示板) には短い説明を足す | 掲示という形 |

## 2. 前半の結論 (**導いた**)

1. 8番出口の面白さは、**題材 (地下通路) ではなく「異変の無い通路で正常を見てから、同じ光景を繰り返して、ずれだけを探す二択」という型**から来る。レビューの言う迷い・疑心暗鬼・「歩いて探すのが落ち着く」はすべて、反復で作る「いつもの姿」への照合から生まれる。人間のフィードバック 5 点目への責任者の推測 (今の版は毎回違う会社の資料を読み込む間違い探しで、同じ空間を繰り返す型の芯を外している) は、この表の「正常を見せてから問う」「毎周ほぼ同じ見た目」と合う。今の版との照らしは #119 で確かめる。
2. 開発者が削ったのは**操作の数と、画面に出す説明**である (写真・銃を捨てて二択、Uターンの手間を捨てて引き返すだけ、座る操作を捨てる、タイトル画面を置かない)。一方、続編では**詰まる所に短い説明を足している**。つまり「**操作は減らす。説明は、世界の中の短い掲示にとどめ、遊び手が詰まる所には足す**」まで言える。「説明を増やすと芯と逆」とまでは、出典から言えない。
3. 失敗が痛い (全て失う) のに離脱しにくいのは、**再開が一瞬**で、1 周が短いから。待ち時間は、離脱の主因になりうる (**導いた**: 続編の試作で「座る動作が面倒」として捨てたことから)。
4. 異変は「気づきにくい細部」と「見れば分かるもの」を**混ぜ**、**見つけるほど残りが難しくなる**出し方で、全部を警戒させる。現行版の「見た目 / 会計」という分け方と出題の仕方が、この混ぜ方・出し方に合っているかは別に確かめる (#119)。

## 5. 後半の結論 (**導いた**)

1. 遊び手は「会計の知識がほぼ無い」を前提にする (人間の前提)。調査は、会計そのものは測っていないが、それと矛盾しない (金融全般の正答率 53.8〜55.7%、18〜29 歳 41.2%、金融教育を受けた人 7.1%〜8.7%、株式の保有 14.1%、株式の指標を知る人 9.8%)。**用語を知らない前提で、画面に出す数字を 4 つ以内、本文を 230〜330 字程度に絞る**のが、根拠から導ける最も強い線 (いずれも §4.3 の仮定つき)。
2. 決算短信・IR スライドの様式は、**網羅して出す設計**。個人投資家は、**統一された書式だから探せる**と評価している (§4.2)。これは「毎回同じ見た目で見せる」型 (前半 §1.2) に合うので、**様式を毎回同じにすることは残し、同時に見せる数字と文字の量を絞る**方向が、出典と矛盾しない。一方、資料を丸ごと再現する今の作り (10 画面) が遊び手の水準に合うかは、#119 で測る。
3. 「やさしく見せる」先行例からは、**枠で構造を見せる・暮らしにたとえる・数字を丸める・1 画面 1 テーマ・身近な単位に換算する・ふりがな・見出し 1 行で向きを言い切り要約 3 文 → 表と深くする**の 7 つの形が確かめられた (§4.5)。決算を 1 画面の量で見せた先行例は無く、量の上限はプレイで確かめる。
4. 『ぎりぎり分かる』水準の実測値は、まだ無い。案ごとに、(a) 数字・文字数・文字の大きさの上限 (§4.3) を守る、(b) 初見のプレイで「何を見て答えたか」を確かめる、を受け入れの形にする。
