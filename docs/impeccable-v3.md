## 3. 残る重大 1 件: 問題データ (#139・#140)

critique A が、本番プール (今の `src/data/problems`) で、やさしいの不正解のあとの 0 社目の説明が「売上総利益は …」(カードに無い欄) になり、朱の場所が出ない問題が多いことを見つけた (seed=21 の 8 社のうち、異変 6 件で朱の場所が出たのは 2 件。推測でなく、画面で見た値)。**原因は画面ではなく、v2 時代の問題データが v3 のカードの形に合っていないこと**: 検証器 (#138) は「異変の場所と主な規則がカードに載る」ことを `card-invisible` で全問に当てる (`src/verifier/cards.ts` の `isVisible`・`src/verifier/dataset.ts`)。データ v3 (#139・#140) が検証器を通れば、この問題は無くなる。
→ **#139・#140 への申し送り**: 作り直す問題は `card-invisible` を通すこと。画面の側は、場所がカードに無い異変でも壊れない (朱の囲みが出ないだけ。説明文は出る)。それまでの本番は、`canDraw` が true のため出題される (責任者の補足: 画面は今のデータで動けばよい)。
