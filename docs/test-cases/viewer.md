# ケース表: 資料束の表示と道具 (Sub-task #62)

Task #57 (画面: 資料束の表示と道具)。受け入れ条件 2・9 (要件)、[experience.md](https://github.com/calliope-pro/kessan-8/blob/calliope/experience/docs/plans/experience.md) §6.5 の SC4-1〜SC4-7 (資料の切替・ページ送り・タブ・道具バー・印・検算)、§6.3 の 1・2・3b、§6.6 (印は `marks`)、設計 [design.md](../design.md) §4.1 (path・itemKey・単位・△・見た目の上書き)・§7。項目名の標準は [labels.md](labels.md) (`src/domain/labels.ts`)。

**範囲**: 資料束の 10 画面の表示、資料の切替・ページ送り・タブ、道具バー (印スイッチ・検算・「判定する」の口)、印、検算、異変の場所を強調する口。**範囲外** (#28 の #59・#60・#61): 状態遷移 (`reduce`)・出題・タイトル・難易度・判定のパネル (SC4-10)・答え合わせ (SC5)・クリア・演出 (V1〜V4・R4〜R6)・記録。見本・導入 (SC2・SC3) も範囲外。並べて見る (T3・T4) は experience.md が後回し。

## 8. このケース表の範囲外と、決めたこと

- 並べて見る (T3)・道具の段階 (T4): experience.md で後回し。
- 判定のパネル・「読みに戻る」(SC4-10)・答え合わせ (SC5)・SC5-7 の照合 (`matchMarks`) と画面表示: #28 (#59・#60)。ここは強調の口までを作る。
- 印は `reading.marks` (design の状態。#59 が持つ) に入る文字列の一覧で、付け外しも #59 の `reduce`。`createViewer` は一覧を受け取り、押されたキーを返すだけ。
- 異変の場所の画面へ移る (`screenOf`)・`VIEW` の遷移は #59 の `reduce`・`domain/answer.ts`。ここのビューアは、`doc`・`screen` を渡されたとおりに出す。
- **G-2 (動きの抑制)**: ビューアにはアニメーションが無い (遷移は即時)。`prefers-reduced-motion` で止める対象は #61 の演出 (V・R) だけ。SC4-1 (閲覧票の帯: 「n / 8 社目」・社名・時刻) は V2・V3 と一緒に #28 (#61) が資料の外に置く。ビューアは資料の見出し (社名・証券コード・期・単位) までを受け持つ。
- 数字の表示は、問題データの値そのまま。ビューアは、合計・比率・差を計算しない (検算の差・比は遊び手の道具で、表示の数字には含めない)。
- 実機 (iOS Safari・Android) の見え方・指での押しやすさ: 公開の通し (#30)。
