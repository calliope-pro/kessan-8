# ケース表: 出題と状態遷移 v3 (Task #155、Sub-task #181)

対象: 受け入れ条件 2・3・5・6 の domain の部分 (docs/requirements.md 第 3 版)。設計: [docs/design-v3.md](../design-v3.md) §1.5 (形の出方の規則)・§2.7 (段は累積・R-S6 の置き換え)・§3.1 の表 10・11・18・21・§3.2 の「#155」の 1〜5。v3 が触れない取り決め (0 社目・`BEGIN`・状態と action・保存・記録) は [docs/design-v2.md](../design-v2.md) §3.1〜§3.4 のまま。
旧: [domain-v2.md](https://github.com/calliope-pro/kessan-8/blob/a098b49/docs/test-cases/domain-v2.md) (#163。形を引く v2。git 履歴 a098b49 の版) は、この表が置き換える。[flow.md](flow.md) の §1.2 (出題)・§1.4 (遷移)・§1.5 (保存と記録) も置き換え済み (flow.md の ID は使わない)。画面 (E2E の §2) は #141 の持ち分で、この表では扱わない。

ブラックボックスで書く: 入力・操作 → 期待する観測結果。対象は、設計に名前のある純粋な関数 (`reduce`・`draw`・`canDraw`・`serialize`/`hydrate`・`recordTransition` ほか) の入出力。内部の構造には依らない。

**v2 の表からの差** (§9 に ID の対応表): 形が 1 つなので、形を引く・形で見える問題を選ぶ・形の出方を数えるケース (DW3・DW4・DW10・DW25c・DW26・DW28 の形の分・DW29・DW30〜DW32) が無くなる。段は累積になる (DW8 の置き換え)。R-S6 は「異変の枠の割合・どの種類も出る・枠の群ごとの種類の偏り」に置き換わる (DW26〜DW29b)。ほかの状態遷移・保存・記録のケースは、枠から形を外すだけ。
